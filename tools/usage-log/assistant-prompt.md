# 폰 사용 기록 조회 설명문

폰 사용 기록(앱 사용, 화면, 알림, 집 도착·출발)은 PC에 쌓여 있다. 사용자가 요청할 때만 아래 명령으로 필요한 범위만 꺼내 읽고, 원본 파일이나 DB는 직접 읽지 않는다.

명령은 `<인터프리터> <usage_log.py 절대 경로>` 뒤에 붙여 실행한다.

| 명령 | 쓰임 |
|---|---|
| `summary 2026-11-13` | 하루 요약 |
| `timeline 2026-11-13 09:00 18:00` | 시간대별 흐름 |
| `notifications 2026-11-13 --app 앱이름 --search 단어` | 알림 찾기 |
| `notifications --new` | 새로 온 알림. 날짜·`--app`·`--search` 없이 쓰고, 이미 읽은 알림은 빠짐 |
| `home 2026-11-13` | 집 도착·출발 |
| `apps 2026-11-07~2026-11-13 --app 앱이름` | 앱 사용 시간 추이 |
| `sql "SELECT ..."` | 위 명령으로 안 될 때만. SELECT만, 최대 200행 |

- 결과 끝에 `외 N줄`이 있으면 날짜·시간대·`--app`·`--search`로 좁혀 다시 조회한다. `--new`는 다시 불러 이어 받는다.
- sql 표는 `records`이고 주요 열은 `type`, `app_name`, `title`, `text`, `ssid`, `home`, `local_t`(현지 시각 epoch 밀리초)다. 답에 epoch 값, 패키지 이름, 알림 key를 쓰지 않는다.
- 알림은 거르거나 묶거나 자르지 않는다. 줄 끝 표시:
    - `열어 봄`: 사용자가 연 알림
    - `지움`: 사용자가 지운 알림
- 집 여부 표시:
    - `알 수 없음`: 기록이 없어 모르는 시간(집 밖이 아님)
    - `(추정)`: 폰이 나중에 알아챈 시각(실제는 더 이를 수 있음)
- 기록은 최대 1시간 늦게 들어오므로 `마지막 기록` 뒤는 아직 모른다.
