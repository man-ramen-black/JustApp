# JustApp 버그로 보고됐지만 원인이 외부인 증상

같은 증상이 다시 보고되면 코드를 고치기 전에 여기서 먼저 확인한다.

## 치지직 PIP 화면이 검게 나옴

- **증상**: 갤럭시 S24(Android 16)에서 치지직 시청 중 제스처로 홈 이동 시 PIP 화면만 검고 소리는 계속 나온다.
- **결론**: JustApp(UsageTimer 오버레이·접근성 서비스)과 무관하다. JustApp 프로세스를 강제 종료하고 접근성 서비스를 모두 끈 상태에서도 재현된다.
- **원인**: 기본 런처가 서드파티(Smart Launcher)이고 제스처 내비게이션일 때, One UI 제스처 처리기가 서드파티 홈 액티비티를 먼저 시작해 치지직이 PIP 전환보다 약 0.75초 먼저 `onPause`를 받는다. 치지직이 그 시점에 백그라운드(오디오 전용) 모드로 바꿔 영상 Surface를 숨긴 뒤 PIP로 들어가 검은 화면이 된다.
    - 기본 런처가 One UI 홈이거나, 홈 키·3버튼 내비게이션이면 정상이다.
- **회피**: 치지직 설정 > 시청 환경 설정 > `백그라운드 재생`을 끄면 같은 조합에서도 정상이다(OFF 3/3 정상, ON 2/2 검은 화면).
- **확인 순서**: 기본 런처와 내비게이션 방식부터 확인한다. 근본 수정은 치지직 쪽 몫이다(`onPause`가 아닌 `onStop`에서 영상 해제, 또는 `PictureInPictureUiState.isTransitioningToPip` 확인).
